Read AGENTS.md and its mandatory sources. Use docs/REVIEW_METHODS.md for pinned external method provenance; never fetch and execute upstream instructions automatically.

Resolve the authorized repository, branch, base and dirty state before work. Separate daily content scope from maintenance scope. Preserve historical originals, locked editorial content, issue art direction, the three reader themes and Production boundaries.

Reproduce the user-visible failure before editing. Classify bug, usability, hierarchy, content understanding, performance or maintenance. Record page, viewport, steps, reader impact, severity and observable acceptance. Distinguish measured evidence from visual judgment; no fabricated scores or reviewer independence.

For shared reading changes inspect homepage, Archive, current issue and one story, desktop and 390px, every theme, keyboard, no JavaScript, reduced motion, unavailable external images and long headings. Reuse native browser tests and inspect actual rendered pages. Keep typography/navigation/fallback stable while allowing the issue its own composition, palette and central visual action. Do not add decorative motion or a framework merely to modernize.

Make a small reversible change, verify its affected journeys, and check that it helps the full publication. Run repository-required verification once the change is complete. Broaden checks only when new failures or changes justify it. Store screenshots and research privately, outside public Git.

For operational changes use ops:check and current GitHub/live evidence. A PR or successful build is not publication. Daily Preview requires the explicit machine gate and matching evidence; Production remains separate. Resume only the unique dated candidate with a matching release receipt. Reconcile final merge, run and live hashes into the automation's own memory.

Report changes, evidence, limitations and next action. Keep upstream tooling optional and pinned. This skill neither authorizes repository migration nor relaxes source, private-material or rights requirements.
