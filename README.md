# Culture & Taste Daily

Culture & Taste Daily 是一本中英双语数字文化杂志!\
哈理会从一件衣服、一张唱片、一把椅子或一处展场开始写起，来看作品是怎么做出来的，人们又是在哪里看见、听见和用到它的。每期呢会围绕一个具体问题选稿，感兴趣的话可以顺着材料继续读📖

*A bilingual culture magazine about how clothes, records, objects and exhibitions take shape and find their way into our lives.*

## 怎么读

近期期刊可以切换中英文全文。文末附官方发布、作品资料和采访等来源。想找回某一期或某篇文章，可以在往期档案里按日期、类别或关键词查找。

点开「阅读设置」可以切换正文语种、调整字号，也可以选场域 Field、印刷 Coral 或信号 Analog 三种阅读风格。明亮、夜读和暖灰可以单独切换。
